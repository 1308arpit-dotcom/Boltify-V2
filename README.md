# ⚡ Boltify – Food Delivery Web Application

Boltify is a modern food delivery web application inspired by Swiggy, built using **HTML5, CSS3, and JavaScript**. It provides a smooth and responsive food ordering experience with an intuitive interface and essential food delivery features.

## 🚀 Features

- 🍽️ Browse restaurants and menus
- 🔍 Search restaurants instantly
- ⭐ Filter by ratings
- 💰 Sort by price and delivery time
- 🛒 Add to cart and manage orders
- 🎁 Offers and coupon system
- 👤 User Sign Up & Login
- 🔐 Local Storage-based authentication
- 💳 Checkout page
- 📦 Order management
- 🛠️ Admin dashboard
- 👥 Manage users, restaurants, and offers
- 📱 Fully responsive design

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage
- Font Awesome
- Google Fonts
